Suggest a question

Waiback asks every model the same fixed set of questions. If you have a good one, propose it and Ted will review it. Strong questions force a model to make a judgment it cannot dodge, and stay meaningful as models change over the years.

Open a question suggestion →

This opens a prefilled issue on GitHub. You will need a free GitHub account. Every suggestion lands in the project's issue tracker for review.

What makes a good question

  • It demands a decision or a stance, not a summary. The standing system prompt tells models not to placate both sides.
  • It is self-contained: no links, no attachments, no context the model would not have.
  • It will still make sense in five years, so the archive stays comparable over time.
  • It is one question (follow-up clauses are fine), phrased the same way for every model.

Prefer email or want to browse the set first? See the current questions, or open an issue directly on GitHub.
