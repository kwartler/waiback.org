Data for researchers

The entire archive is open. Every model is asked the same fixed questions under identical conditions (temperature 0 and one shared system prompt), and each answer is stored with the model's release date and the date it was collected, so you can study how answers shift as models are released and updated over time. Free to use for research and journalism with attribution.

How to obtain the data

  • Programmatic (JSON). Start at /api/index.json, a catalog of every model and question with links to:
    /api/models/<slug>.json (one model, its full answer sheet) and /api/questions/<id>.json (one question, every model's answer).
  • Bulk / raw. The whole repository is public: github.com/kwartler/waiback.org. The data/ folder holds questions.csv, models.json, responses.json (every answer), prompts.json (the capture conditions over time), and the generated api/ files.
  • Reproducible. The capture and build scripts (build/generate.py, build/render.py) are in the same repo, so the full pipeline is inspectable.

What each record contains

Per-answer fields: question_id, answer, response_date (collected), prompt_tokens, completion_tokens, total_tokens, input_per_1m and output_per_1m (USD per million tokens, frozen at capture), cost_usd (computed from those), or_cost (OpenRouter's reported charge), temperature, and prompt_sha (which system prompt was used). Per-model records add release_date, knowledge_cutoff, context_length, pricing, and description.
